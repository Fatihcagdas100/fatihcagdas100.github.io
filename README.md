# Fatih Çağdaş - Kişisel Portfolyo / Personal Portfolio

[Türkçe](#türkçe) · [English](#english)

## Türkçe

GitHub Pages üzerinde yayımlanan, mobil uyumlu ve iki dilli kişisel portfolyo sitesi.

### Özellikler

- Türkçe ve İngilizce sayfalar
- Eğitim, deneyim, proje ve beceri bölümleri

### Yerel önizleme

```powershell
python -m http.server 8000
```

Ardından Türkçe sürüm için `http://localhost:8000`, İngilizce sürüm için
`http://localhost:8000/en/` adresini açın.

## English

A responsive, bilingual personal portfolio website published with GitHub Pages.

### Features

- Turkish and English pages
- Responsive dark theme
- Education, experience, projects, and skills sections
- Accessible navigation and reduced-motion support

### Local preview

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000` for Turkish or `http://localhost:8000/en/`
for English.
